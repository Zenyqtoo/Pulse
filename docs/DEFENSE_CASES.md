## Новые сайты

Сборщик `city_web` поддерживает два явно разрешённых домена: `gorodpavlodar.kz` и `obozrenie.kz`. Доступны публичные HTML-статьи, заголовок и фрагмент до 900 знаков, действительная дата и исходная ссылка. Для повторного сбора выберите источник и «Запустить»: сборщик читает актуальную главную/новостную страницу, проверяет robots.txt и выдерживает паузу не меньше трёх секунд. За запуск — не более 20 статей. Планировщик локального демо выключен; это не обещание постоянного мониторинга.

Первый целевой запуск добавил **5 статей: 3 gorodpavlodar.kz и 2 obozrenie.kz**. Это не пять новых сообщений жителей. В публичном снимке теперь **396 реальных записей и 104 учебных**, 46 групп с учётом сохранённых неактивных и трёх редакторских подборок. Архивные даты 2024–2025 годов также сохранены; для них нужен широкий период фильтра.

Если разметка сайта или дата не распознана, запись пропускается с предупреждением; дата сбора не подставляется вместо даты публикации. Не обещать независимость перепечаток. Обход защиты irbistv.kz не выполняется. Instagram и Telethon этим изменением не подключены. Экспериментальная локальная модель остаётся выключена.

## Воспроизведение

Включённый `public_snapshot.json` содержит сами записи и подготовленные группы. На новой установке используйте `python -m app.cli load-snapshot` по README. Сборщики снимка намеренно выключены: новые источники добавляются из каталога вручную.

Если нужные записи уже загружены, группы можно подготовить повторно:

```bash
python -m app.cli prepare-defense
```

Команда использует URL из `backend/app/data/defense_cases.json`, не создаёт отсутствующие сообщения и не сочиняет тексты. Повторный запуск обновляет те же подборки. Действие записывается в аудит. API `/api/defense/cases` требует входа и соблюдает ограничение пользователя по подразделению.
