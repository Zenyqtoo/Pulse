Решение пользователя 02.11.2026: пока не использовать обученную модель в основном продукте, сохранить её для будущего развития.

## Что сохранено внутри проекта

- `backend/app/local_model_assets/`: обученные классификаторы v4, словари и IDF, версии и model cards, отчёт сравнения;
- открытая основа E5 закреплена на ревизии `614241f622f53c4eeff9890bdc4f31cfecc418b3`;
- код обучения, подготовки данных, сравнения и отдельного локального стенда в `backend/scripts/`;
- лёгкий адаптер `app/ai/local_client.py`, подключаемый только при явном opt-in;
- тесты поведения отключённого/включённого модуля и резервного режима;
- `requirements-local-ml.txt` для отдельного окружения.

Копия обученных голов занимает около 13 MB. Полные веса открытого кодировщика хранятся отдельно в кеше и при необходимости скачиваются явной командой. Рабочая база, ключи сервисов и виртуальные окружения в комплект модели не входят.

## Текущее поведение

`LOCAL_MODEL_ENABLED=false` — значение по умолчанию в Settings и `.env.example`. Локальный демолаунчер также явно задаёт false. Основной backend не импортирует torch/transformers, не запускает сервис и не скачивает веса. Обычный rules/Claude-путь сохранён; наличие архива не меняет обработку сообщений.

Локальная страница :8012, если ещё открыта, — отдельный стенд для экспериментов. Она не означает, что модель включена в основном сайте :8000. Закрытие страницы также не меняет настройки backend.

## Как вернуться к модели позже

Сначала проверить качество новой модели на реальной независимой выборке. Сохранённая v4 — прототип; основные ограничения и результаты в [LOCAL_MODEL_V4.md](LOCAL_MODEL_V4.md).

На текущем ноутбуке из корня хакатона можно запустить сохранённую проектную копию:

```powershell
$env:HF_HUB_OFFLINE='1'
.\.runtime\ml-venv\Scripts\python.exe Pulse/backend/scripts/serve_local_model.py --model Pulse/backend/app/local_model_assets --cache .runtime/hf-cache --report Pulse/backend/app/local_model_assets/report.json --port 8012
```

Если порт уже занят стендом, повторно запускать не нужно. Перед остановкой процесса всегда сверять его командную строку.

На другой машине создать отдельное Python-окружение, установить `backend/requirements-local-ml.txt`, затем из корня репозитория один раз скачать основу:

```bash
python backend/scripts/download_local_encoder.py --cache backend/data/ml-cache
python backend/scripts/serve_local_model.py --model backend/app/local_model_assets --cache backend/data/ml-cache --report backend/app/local_model_assets/report.json --port 8012
```

Первая команда требует интернет для публичного скачивания, но не API-ключа. Сервис использует только локальные файлы и слушает 127.0.0.1. На сайте стенда можно вводить сообщения без анкет/разметки; введённые тексты не сохраняются.

## Явное включение в обработку сообщений (в будущем)

После проверки модели и ручного запуска сервиса в окружении backend задать:

```dotenv
LOCAL_MODEL_ENABLED=true
LOCAL_MODEL_URL=http://127.0.0.1:8012
LOCAL_MODEL_TIMEOUT_S=10
```

Перезапустить backend. Для `work/pulse-study/run_demo.py` дополнительно изменить его явный override false; иначе значение `.env` не подействует. Не делать этого сейчас: пользователь выбрал отключённый режим.

Адаптер передаёт маскированный текст, контекст родительской публикации и фактический kind. Обученные задачи — подразделение, тональность, тип; извлечение сущностей, спам и срочность дополняются существующими правилами. Экспериментальная география не используется как уверенный фильтр: требуется проверка. Версия записывается как `local:cityalert-e5-routed-v4`.

Поскольку баллы не откалиброваны, адаптер выставляет уверенность 0 и отправляет результат на штатную проверку. При недоступности сервиса возвращаются явно маркированные `rules-v1 (local fallback)` с необходимостью проверки. В локальном режиме fallback **не вызывает внешний Claude API**.

Адрес ограничен loopback HTTP; перенаправления и системный HTTP proxy отключены. Это модуль одного компьютера, не готовая схема сетевого production-развёртывания. Для отдельного контейнера/сервера потребуется иной согласованный способ размещения, а не подмена URL внешним адресом.

Чтобы снова отключить: `LOCAL_MODEL_ENABLED=false` и перезапуск backend. Ни архив, ни рабочие данные удалять не нужно.
